# نظام أونكس ERP — الإصدار 8.0

نظام تخطيط موارد المؤسسة (ERP) محاسبي متكامل، مبني بـ **PHP + MySQL + Bootstrap 5 + Tailwind CSS + JavaScript**، مطابق لنظام أونكس الأصلي (من شركة يمن سوفت) بناءً على كتاب "كتاب الاونكس للطالب 2024".

## 🎯 المميزات

- **4 مراحل كاملة** (التهيئة + المدخلات + العمليات + إدارة النظام)
- **45 شاشة فعّالة** موزعة على هرم إداري واضح
- **50 جدول** في قاعدة بيانات MySQL مع علاقات كاملة
- **نفس تصميم نظام أونكس الأصلي** (شريط جانبي داكن نيلي، شاشة دخول احترافية)
- **دعم كامل للعربية و RTL**
- **توليد قيود محاسبية تلقائيًا** عند حفظ السندات والفواتير
- **تحديث المخزون تلقائيًا** عند ترحيل أوامر التوريد والصرف والتحويلات
- **نظام مصادقة آمن** بـ password_hash + sessions + CSRF

## ⚙️ التثبيت

### المتطلبات
- PHP 7.4+ (يفضّل PHP 8.0+)
- MySQL 5.7+ / MariaDB 10.4+
- خادم Apache مع mod_rewrite (اختياري)

### خطوات التثبيت

1. **انسخ الملفات** إلى مجلد الخادم:
   ```bash
   git clone https://github.com/ENG-ANAS-RASSAM/onyx-erp.git
   cd onyx-erp
   ```

2. **عدّل إعدادات قاعدة البيانات** في `config/config.php`:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'onyx_erp');
   define('DB_USER', 'root');
   define('DB_PASS', '');
   ```

3. **استورد قاعدة البيانات**:
   ```bash
   mysql -u root -p < database/schema.sql
   ```
   أو من phpMyAdmin: استورد الملف `database/schema.sql`

4. **شغّل معالج التثبيت** في المتصفح:
   ```
   http://localhost/onyx-erp/install.php
   ```
   أنشئ حساب المدير (الافتراضي: `admin` / `admin123`)

5. **احذف ملف `install.php`** بعد التثبيت:
   ```bash
   rm install.php
   ```

6. **افتح النظام**:
   ```
   http://localhost/onyx-erp/login.php
   ```

## 🔐 بيانات الدخول الافتراضية

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin123`
